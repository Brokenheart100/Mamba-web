# Nuxt UI、液态玻璃与多源补充

日期：2026-10-16（Asia/Shanghai）。本页记录此次修改，首版验证记录保留在 verification.md。

## 已实现

- 使用 Nuxt UI 4.12.0：UApp、UNavigationMenu、UButton、UCard、UInput、USelect、UTabs、USwitch、USlider、UModal、UBadge 和 UAlert。
- 统一系统字体、iOS 蓝色强调、圆角控件、分段选择与浅色 / 深色外观。
- GlassCard 封装 UCard，提供半透明背景、24px 背景模糊、饱和度、边缘高光与指针光斑。主体面板、选集和历史列表使用一致材质。
- 桌面侧栏可隐藏并保存；手机侧栏浮层可展开、选择后关闭。减少动态效果偏好会关闭动画，不支持 backdrop-filter 时提供实色背景。
- 来源管理页支持名称筛选、单源 / 批量检测、启停和恢复默认。开关在本地偏好读取完成后开放，避免 SSR 初始状态与本地状态竞争。
- 播放页以 3 路并发检索启用源，按返回顺序补充线路并支持按源筛选。换线与检索分别取消请求；上次来源优先，失败尝试未尝试的精确匹配线路。
- 观看记录继续只保存在 IndexedDB，没有账户和服务端观看记录库。

```powershell

# 或读取已下载的订阅文件
node scripts/update-source-catalog.mjs C:\path\subscription.json
```

输出只写入 `output/source-research/catalog-proposed.json`，不会自动替换运行目录。比较差异、检查域名和选择器、验证搜索和播放后再更新 `server/providers/video/source-catalog.json`。

## 本地验证

- SFC 解析检查和 TypeScript 检查通过。
- 4 个测试文件、23 项测试通过。新增覆盖 17 个来源唯一性、固定域名边界、三类搜索格式、章节类型 / 小数、JSON 包装 HTML、播放配置解码及可执行配置拒绝。
- Nuxt 生产构建通过，生产 Node 预览保留在 `http://127.0.0.1:3100`。
- Edge 实际播放：稀饭备用 HLS 时长约 1559.93 秒、叽哔 1 线约 1559.92 秒、樱花线路 1 约 1665.28 秒；媒体处于播放状态且时间前进。不同来源片头或剪辑可能不同。
- 继续读取首版保存的 154.038 秒记录，没有写入零秒覆盖；换源继续沿用当前位置。最终构建再次进入播放页时优先恢复上次樱花线路 1，视频继续播放，11 个默认源共返回 45 条候选线路。
- Nuxt UI 设置：默认音量从 75% 调至 70%、倍速 1.5、弹幕关闭，刷新仍保留；清空记录弹窗可取消。
- 来源开关关闭、刷新、恢复开启均能保存；名称筛选和单源 / 批量检测可操作。批量检测在响应到达后合并最新状态，避免并发响应互相覆盖。
- 桌面侧栏隐藏并刷新保留；恢复侧栏、切换深色外观正常。
- 390 × 844 Edge 移动视口无横向文档溢出，17 张源卡可查看，导航选择后关闭。
- 这些是桌面 Edge 和移动视口验证；Safari、iOS / Android 真机、长期可用性、容器与公网部署尚未验收。
