# ArtPlayer 播放器迁移

日期：2026-10-16（Asia/Shanghai）。这是本机验证记录，不代表所有第三方线路或手机真机均通过验收。

## 实现

- ArtPlayer 5.4.0 + 官方 artplayer-plugin-danmuku 5.3.0，继续使用已有 hls.js 1.7.3。
- 保留 VideoPlayer 的组件名称、flush / position 暴露接口，以及 progress / fatal / settings 事件。播放源适配、签名、记录导入导出和无账户架构继续沿用。
- 客户端生命周期内动态导入，避免服务端访问浏览器 DOM；播放器按媒体 URL 重新创建。
- 原生 MP4、HLS、倍速、宽高比、画中画、浏览器全屏和网页全屏。播放器控制栏与设置面板采用单独的玻璃样式。
- 弹幕开关、透明度、字号、速度、显示区域、显示类型、防重叠和速度同步设置均写入 IndexedDB。时间偏移继续支持 -300 到 300 秒。
- 兼容旧 v1 设置行：读取时补齐新增字段，保留已有音量、倍速、开关、透明度和偏移，不需要重建数据库。
- 本地 XML / JSON 解析和格式校验保持不变，适配器复制数据并转换模式和时间。插件对输入的修改不影响本地原始弹幕。零秒弹幕转换为 1 毫秒，避免插件将 time:0 视为立即发送。
- 弹幕发送入口关闭。播放器体验页增加本地演示弹幕，仍不写入观看记录。
- 拖动时重置弹幕显示队列；弹幕池替换串行执行并丢弃过时任务。字幕与剪辑差异仍需通过偏移手动调整。
- ArtPlayer 自动续播关闭，继续由应用恢复本地进度；自动重连关闭，继续由观看页尝试其他精确匹配线路。首次加载 25 秒没有就绪会报告失败。
- 卸载时销毁 HLS、ArtPlayer 和插件 Worker，并移除页面监听与超时；尚未播放时不保存零秒进度。
- 进度事件携带该实例的来源快照，旧播放器卸载补写不会把旧画面的进度误标为新来源。

## API 与边界

已核对官方文档与安装包类型 / 实现：

- [ArtPlayer 基础选项](https://artplayer.org/document/start/option)
- [实例属性与销毁](https://artplayer.org/document/advanced/property)
- [实例事件](https://artplayer.org/document/advanced/event)
- [官方弹幕插件](https://artplayer.org/document/plugin/danmuku)

在线弹幕源仍未接入。当前内容来自本地文件或体验页的演示数组。第三方播放器不会解决源站鉴权、CORS、加密解析或浏览器不支持的编码。

Safari / iOS / Android 真机尚未验证。手机系统原生视频全屏的 DOM 弹幕叠加能力需要单独验收，网页全屏保留应用内弹幕层。画中画通常只显示视频，不能据此宣称弹幕也进入系统画中画窗口。

依赖安装时仍报告原有 12 项审计问题（1 low、11 high），未执行强制降级。公网部署、容器与依赖风险处置仍参见此前验证记录。
