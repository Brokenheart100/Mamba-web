- 本地持久化和版本化导出。
- 倒退观看与已看状态保留。
- 迟到的旧快照不覆盖新记录。

- 导入按更新时间合并。
- 导入全量校验，错误数据不造成部分写入。

- 标题规范化保留季度差异。
- 非 HTTPS 与内嵌账号密码的自定义地址拒绝。
- 弹幕排序、文本与颜色校验。
- 播放凭证签名、篡改、任意 URL 路径和过期校验。

## 尚未完成的验收与功能

- Chrome、Firefox、Safari、iOS 和 Android 真机没有验证。移动视口截图不等于手机兼容性验收。
- 上游全部番剧、线路的长期可用性未验证。主线 401 是真实上游失败，备用 HLS 可播不能证明其他线路都可用。
- 聚合在线弹幕未接入，当前为本地 XML/JSON 弹幕。
- BT、转码、媒体代理、视频离线下载、ASS 字幕未实现。
- Dockerfile 已提供，镜像构建与容器内播放尚未验证。
- 公网 HTTPS、反向代理、负载、多实例、持续可用性未验证。

## 依赖审计

`npm audit` 与 `npm audit --omit=dev` 报告 11 项 high，主要传播自 Nuxt/Nitro 构建依赖链中的两个底层条目：

- `braces@3.0.3`：[GHSA-vfj7-8cjw-p6xm](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm)。
- `node-forge@1.4.0`：[GHSA-86w9-cpqp-85rv](https://github.com/advisories/GHSA-86w9-cpqp-85rv)。

已执行兼容范围内的 `npm audit fix`，没有解决这些报告。当时 npm 查询仍以这两个版本为最新；没有执行建议强制降级 Nuxt 的 `--force`。本次生成的 `.output/server/node_modules` 未发现 `braces` 或 `node-forge`，但这不等于整体风险已处置。公网发布前应重新审计、评估构建链影响并处理。

构建另有 hls.js 动态块大于 500 kB 与 Vue 包导出弃用提示；构建可完成，HLS 引擎按播放需求动态加载。
